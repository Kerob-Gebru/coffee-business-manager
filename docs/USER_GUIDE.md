# First-use guide

1. Sign in with the development admin account described in the root README.
2. Open Dashboard to see system status and module shortcuts.
3. Open Contacts to register customers, suppliers, exporters, employees, drivers or other contacts. A contact may carry more than one role.
4. Open Finance to record a transaction in its original currency. The initial form is a basic record-entry foundation, not yet a complete invoice/payment allocation workflow.
5. Use the theme control to switch light/dark mode. The language selector is a UI foundation; full translations are planned.

Use sample data only until authentication, permissions, audit history, backup and accounting workflows have been reviewed for your business.
